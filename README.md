# AI-Based Student Performance Prediction System

A beginner-friendly console mini-project integrating the existing Python + SQLite student CRUD system with a genuine scikit-learn Decision Tree classifier.

## Important dataset note
`synthetic_student_performance.csv` contains **synthetic demonstration data generated by a program**. It is not collected from real students and must not be represented as real-world evidence. The model learns the patterns intentionally built into this simulated dataset. Its evaluation score does not establish performance on real students.

## Features
- Add, view, search, update, and delete student records
- SQLite storage in `students.db`
- Predict a performance category for a saved student or new input
- Training/test split with stratification
- Decision Tree Classifier from scikit-learn
- Held-out test accuracy, classification report, and confusion matrix
- Basic study suggestions based on input thresholds
- Validation for names, numbers, marks, attendance, study hours, and semester
- Database migration adds new columns to an older `students.db` without deleting existing records

## Requirements
- Python 3.10 or newer recommended
- Internet access only to install dependencies (unless already installed)

## Run on Windows
1. Extract this ZIP.
2. Open the extracted folder in VS Code or Command Prompt.
3. Open a terminal in the project folder that contains `requirements.txt` and `main.py`.
   If you opened the outer ZIP folder instead, change into the app folder first:

   ```powershell
   cd .\ai_student_performance_prediction
   ```

4. Create a virtual environment (recommended):

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   If PowerShell blocks activation, use Command Prompt:
   ```bat
   .venv\Scripts\activate.bat
   ```

5. Install dependencies:

   ```powershell
   python -m pip install -r requirements.txt
   ```

6. Run the app:

   ```powershell
   python main.py
   ```

The included CSV is used by default. If it is missing, the program creates a new reproducible synthetic CSV automatically. `students.db` is created automatically when you first run the app.

## Menu
1. Add student — includes current marks plus previous marks, attendance, and study hours
2. View all students
3. Search student by name
4. Update a student
5. Delete a student
6. Predict for a saved student
7. Predict from new inputs without saving
8. Evaluate the model
9. Exit

## Model design
- Features: `previous_marks`, `attendance_percent`, `study_hours_per_day`
- Target: `performance_category` (`Needs Support`, `Average`, `Strong`)
- Algorithm: `DecisionTreeClassifier(max_depth=5, min_samples_leaf=8, class_weight="balanced")`
- Split: 75% training / 25% held-out test data, fixed random seed, stratified by class
- Metrics: accuracy, per-class precision/recall/F1, confusion matrix

The synthetic target is generated from a simulated score that combines previous marks, attendance, study hours, and random noise. This makes the project reproducible and suitable for demonstrating the ML workflow, but it can also make the test results look better than real-world performance.

## Suggested demonstration
1. Run the app and choose option 8 to show model evaluation.
2. Choose option 7 and enter sample inputs, e.g. previous marks `72`, attendance `85`, study hours `3`.
3. Choose option 1 to save a student record.
4. Choose option 6 and enter the ID shown when adding the student.
5. Choose option 2 to show the saved prediction.
6. Try invalid inputs (e.g. attendance `150`) to demonstrate validation.

## Limitations and responsible use
- Synthetic data is not evidence of real-world model accuracy.
- The displayed predicted-class probability is a model probability, not a guarantee or calibrated probability of success.
- Study suggestions use simple rules, not a generative AI model.
- Do not use this prototype to make high-stakes decisions about students.
- For a stronger real-world project, obtain an appropriate, permissioned dataset and evaluate on representative unseen data.
