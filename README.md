A beginner-friendly Python mini-project that combines a student management system with a machine learning model for predicting academic performance.

This project uses SQLite for record storage and a scikit-learn Decision Tree classifier to classify student performance into `Needs Support`, `Average`, and `Strong` categories.

## Important dataset note
`synthetic_student_performance.csv` is a synthetic demonstration dataset generated by the program itself. It is not collected from real students and must not be presented as real-world evidence. The model learns patterns from the simulation, not from actual academic outcomes.

## Features
- Add, view, search, update, and delete student records
- SQLite storage in `students.db`
- Predict a performance category for a saved student or fresh inputs
- Stratified training/test split for model evaluation
- Decision Tree Classifier from scikit-learn
- Accuracy, classification report, and confusion matrix output
- Basic study suggestions based on the predicted category and input values
- Input validation for marks, attendance, study hours, and semester
- Automatic database migration for older `students.db` files

## Run on Windows
1. Open a terminal in the project folder.
2. Create a virtual environment:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   If PowerShell blocks activation, use Command Prompt instead:

   ```bat
   .venv\Scripts\activate.bat
   ```

3. Install dependencies:

   ```powershell
   python -m pip install -r requirements.txt
   ```

4. Run the app:

   ```powershell
   python main.py
   ```

The included CSV is used by default. If it is missing, the program creates a fresh synthetic CSV automatically. `students.db` is created the first time the app runs.

## Menu
1. Add student
2. View all students

4. Update student
5. Delete student
6. Predict for a saved student
7. Predict from new inputs without saving
8. Evaluate the model
9. Exit

## Model design
- Features: `previous_marks`, `attendance_percent`, `study_hours_per_day`
- Target: `performance_category` (`Needs Support`, `Average`, `Strong`)
- Algorithm: `DecisionTreeClassifier(max_depth=5, min_samples_leaf=8, class_weight="balanced")`
- Split: 75% training / 25% held-out test data with a fixed random seed and stratification
- Metrics: accuracy, precision/recall/F1 per class, confusion matrix

## Suggested demo flow
1. Run the app and choose option 8 to view model evaluation.
2. Choose option 7 and test a sample input such as `previous marks = 72`, `attendance = 85`, `study hours = 3`.
3. Choose option 1 to save a student record.
4. Choose option 6 and predict for the stored student.
5. Choose option 2 to review the saved data.
6. Try invalid inputs such as attendance above 100 to see the validation logic.

## Responsible use and limitations
- Synthetic data is not evidence of real-world accuracy.
- Predicted class probabilities are model estimates, not guarantees of future performance.
- Study suggestions are basic rules and not AI-generated academic advice.
- This prototype is meant for learning and demonstration only.
- Do not use it for high-stakes decisions about students.
- For real-world deployment, use a permissioned dataset and evaluate on representative unseen data.
